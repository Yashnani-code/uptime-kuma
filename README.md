# Uptime Kuma DevOps Project

## Project Overview

This project demonstrates deployment and monitoring using:

- AWS EC2
- Jenkins
- Docker
- SonarQube
- OWASP Dependency Check
- Trivy
- Uptime Kuma
- Flask
- Twilio
